# EDA AI Circuit

这是一个与“AI 画 PCB 图案”完全独立的新扩展，目标是让 AI 帮你做电路设计，不是画装饰图。

## 当前能力

- 根据自然语言需求生成结构化电路方案
- 自动新建原理图和关联板子
- 自动放置标题、功能分区框、基础器件和基础导线
- 兼容两类常见大模型接口：
  - `/v1/chat/completions`
  - `/v1/responses`
- 如果接口实际返回的是 HTML 网页而不是 JSON，扩展会直接提示这是网页/网关页，而不是模型 API 返回。
- 如果你只填写到基础路径，例如 `https://.../v1`，扩展会自动补成具体端点。
- 如果新建原理图失败，扩展会自动回退到当前已打开的原理图页继续生成内容。

## 推荐使用方式

1. 填写 `API Key`
2. 选择接口模式：
   - `自动判断`：推荐，按 URL 自动识别
   - `Chat Completions`
   - `Responses`
3. 输入简单电路需求
4. 先点“AI 生成电路方案”
5. 检查 JSON
6. 再点“创建基础原理图”

## 建议先测试的需求

```text
帮我设计一个 AMS1117-3.3 最小系统，输入 5V，输出 3.3V，包含输入输出电容、电源指示 LED，并生成基础原理图。
```

## 注意

- 这不是完整自动布线工具，当前更像“AI 自动搭好基础原理图骨架”
- 如果接口返回 `500/503`，除了可能是接口格式不匹配，也可能是第三方服务本身暂时不可用
