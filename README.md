# EDA AI Circuit

这是一个与“AI 画 PCB 图案”完全独立的新扩展，目标是让 AI 帮你做电路设计，不是画装饰图。

## 目标方向

- 根据自然语言需求生成结构化电路方案
- 自动新建原理图
- 自动放置基础器件
- 自动拉基础导线
- 后续再衔接 PCB 生成和布局

## 当前 MVP 计划

第一版先聚焦：

1. 输入需求，例如“做一个 5V 转 3.3V 的 AMS1117 最小系统”
2. AI 输出结构化 JSON 方案
3. 扩展在嘉立创 EDA 中自动新建原理图
4. 自动放置器件、标题和基础导线

## 注意

这不是完整自动布线工具，第一版更像“AI 自动搭好基础原理图骨架”。
